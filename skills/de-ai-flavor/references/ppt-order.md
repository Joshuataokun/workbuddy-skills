# PPT 版式去 AI 味：阅读顺序规则

## 为什么并排算 AI 味

汇报是线性的。讲者按顺序说话，观众按顺序听，视线一路向前不回头。

一页里如果同时有两条通路——左边三栏从左往右，下面一段从上往下——观众看到第一眼就得做一个选择：先横着看，还是先竖着看。这个选择花的时间不长，但它每页都要做一次。二十页下来，注意力就散在"我该看哪"上，而不是内容上。

AI 生成的版面特别容易犯这个毛病，因为它是在"把信息摆满"而不是"把话讲清楚"。三栏、四格、bento 网格，本质都是把一段话切成几块放在同一高度——看起来整齐，读起来要转两次视线。

**一句话判据：一页只能要求观众沿一个方向移动视线。转弯就是问题。**

## 三种合法版式

### 1. 纯纵向（默认，绝大多数页都用这个）

```
┌──────────────────────────────────┐
│ 标题：一句判断，带数字更好        │
│                                  │
│ 一句话结论                        │
│                                  │
│ 支撑 1（一到两行）                │
│ 支撑 2（一到两行）                │
│                                  │
│ 结论/下一步                       │
└──────────────────────────────────┘
```

- 全部左对齐，一条竖线下来
- 文字块之间靠间距分层，不靠色块
- 数据、图放在文字右侧或下方，作为**支撑**，不打断主线
- 适合：背景、问题、举措、结论、下一步

### 2. 纯横向（只在真并列时用）

```
┌──────────────────────────────────┐
│ 标题：一句判断                    │
│                                  │
│ 2023 ──── 2024 ──── 2025 ────     │
│ 立项 3    立项 5    立项 3         │
│                                  │
│ 一句话说明这条线的意思             │
└──────────────────────────────────┘
```

- 单元之间是**同一层级、同一种东西**（时间点、厂区、指标、阶段）
- **每个单元只有一行字**。一行放不下，说明它不是并列项，是段落
- 横向单元 3–5 个为限，超过就拆页或换纵向
- 适合：时间轴、阶段划分、同质对比、指标墙

### 3. 主纵向 + 右侧注释栏

```
┌─────────────────────────┬────────┐
│ 标题：一句判断           │ 3.2 亿 │
│                         │ 合同额 │
│ 左边正文一路往下推进     │        │
│ 这里写主体内容，可以       │ 来源： │
│ 两三段                    │ 台账   │
│                         │        │
│ 结论                     │        │
└─────────────────────────┴────────┘
```

- 右侧那一列只放**数字、单位、来源、图例、注释**
- 右侧不能放第二列正文。放了就变成两栏正文，观众不知道先读哪边
- 宽度比大致 7:3 或 8:2

## 六种要改的版面

### 症状 1：三栏并排 + 下方压一段正文

```
✗ 标题
┌────┬────┬────┐
│ 一 │ 二 │ 三 │   ← 横着读
└────┴────┴────┘
─────────────────
下方一段完整正文…   ← 又竖着读
```

**为什么乱**：上下两套方向。上半页观众横着扫完三个框，视线回到最左，再竖着读下面一段。每页转弯一次。

**改法**：二选一。
- 如果三栏只是同一句话的三个分句 → 合成纵向三段，一路往下
- 如果下面那段才是主体 → 删掉三栏，把三栏里真正有用的信息并进下面那段

### 症状 2：三栏里每栏两行以上

```
✗ ┌────────┬────────┬────────┐
  │ 标题一  │ 标题二  │ 标题三  │
  │ 正文两行│ 正文两行│ 正文两行│  ← 横向里套纵向
  └────────┴────────┴────────┘
```

**为什么乱**：观众横着看完三个标题，还得回头到每一栏里竖着读两行。一次转弯变成三次。

**改法**：每栏压到**一行**。压不下去就说明这三项不是并列关系，改纵向三段，每段一个小标题。

### 症状 3：左右两栏都是正文

```
✗ ┌────────────┬────────────┐
  │ 正文段落    │ 正文段落    │
  │ 正文段落    │ 正文段落    │
  └────────────┴────────────┘
```

**为什么乱**：没有主次。观众第一眼无法判断哪边是重点。

**改法**：左边正文 + 右边只放数字/图表/来源。或者左右合成一段，做成上下推进。

### 症状 4：网格化（上中下三层，每层再左右分）

```
✗ ┌──────┬──────┐
  │ ①    │ ②    │
  ├──────┼──────┤
  │ ③    │ ④    │
  ├──────┼──────┤
  │ ⑤    │ ⑥    │
  └──────┴──────┘
```

**为什么乱**：要求观众走 Z 字或 S 字。这是九宫格海报的逻辑，不是汇报的逻辑。

**改法**：挑出真正的主线（通常只有 1–2 条），其余降级为附注或拆页。六个格子里通常有三个是凑数的。

### 症状 5：单页文字超载

**判断**：超过 120 字就开始挤，超过 150 字基本念不完。

**为什么乱**：不是方向问题，是节奏问题。讲者念到一半，观众已经在自己往下读了，两边对不上。

**改法**：把这一页那句话写下来（一句话），只留支撑这句话的内容。剩下的细节进备注页或附录。

### 症状 6：跨页版式同构

**判断**：连续五页以上，每页元素数量完全一样（都是"1 个标题 + 3 个框"）。

**为什么乱**：翻页时没有节奏变化，观众会产生"这页看过了"的错觉，直接走神。

**改法**：按内容角色换版式——封面、数据页、过程页、对比页、结论页，各自长得不一样。至少每四五页要有一页密度明显不同（比如一页只有一句话和一个大数字）。

## 标题怎么写

一个标题，一条标准：**念出来就是这一页的开场白。**

| 不要 | 要 |
|---|---|
| 以数字赋能促管理提升，以闭环管控固经营根基 | 电气类停机占非计划停机的 39% |
| 主要工作举措 | 三个月完成 11 项变更立项，8 项已批复 |
| 关于下一步工作思路的思考 | 明年重点砍掉两项低效投入 |
| 项目建设情况汇报 | 进度滞后 27 天，卡在征地 |
| 凝心聚力 攻坚克难 全面推动高质量发展 | 产量回到设计值，成本还高 8% |

**三条禁令：**
1. 不对仗。`以 X 促 Y`、`既 A 又 B`、`凝心聚力·攻坚克难` 这类，读起来顺，但观众记不住任何事实
2. 不用名词短语结尾。`…的思考` `…的情况` `…工作汇报` 都是把问题藏在名词里
3. 不超过一行。一行放不下，说明这一页想说两件事，该拆页

## 常见汇报页的重构

**背景页**
- 不要：三栏"政策背景 / 行业趋势 / 自身需求"
- 要：一句判断（"立项变更集中在三个原因上"）→ 纵向列三条原因，每条带数字

**举措页**
- 不要：六个图标围成一圈，或 2×3 宫格
- 要：纵向排 2–3 条真举措，每条一行动作 + 一行结果

**成效页**
- 不要：四个彩色 KPI 卡横排 + 下面一段总结
- 要：一句结论标题 + 一个主数字（大）+ 两三个支撑数据（小，纵向排）

**问题页**
- 不要：三栏"问题 / 原因 / 对策"一一对应
- 要：纵向列问题，每条后面直接跟原因，对策另起一页

**计划页**
- 不要：甘特图占满全页、文字挤在格子外面
- 要：横向时间轴（唯一合法的横向用法），每个节点一行字

## 改版动作顺序

1. 写下这一页要说的**一句话**（不许两句）
2. 定方向：纵向还是横向，只能一种
3. 删掉所有不支撑那句话的元素
4. 按方向排：纵向一路左对齐往下；横向每单元只留一行
5. 最后才调字号、留白、配色

**顺序不能反。** 先调美化再改结构，等于给一棵长歪的树刷漆。

## 验收清单

一页一页过，任何一条为否就改：

- [ ] 这一页有没有同时出现并排多栏和纵向段落？（有 → 拆）
- [ ] 横向单元里有没有超过一行的？（有 → 压成一行或改纵向）
- [ ] 左右两栏是不是都是正文？（是 → 右边改成注释栏）
- [ ] 正文有没有超过 150 字？（有 → 砍进备注）
- [ ] 要点有没有超过 5 条？（有 → 合并或拆页）
- [ ] 标题能不能直接念出来当开场白？（不能 → 重写）
- [ ] 标题有没有对仗、口号、名词短语结尾？（有 → 重写）
- [ ] 连续五页是不是同一个模子？（是 → 换版式）
- [ ] 数据有没有来源和口径？（没有 → 补或标待补）
- [ ] 有没有渐变紫蓝底、圆角卡片堆、bento 网格、图标雨、3D 球？（有 → 全删）
