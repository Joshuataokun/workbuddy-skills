# Trigger Tests — 触发自测表

用途：验证 `description` 能否被正确命中。改完描述后跑一遍，得到触发率。
方法：在**新会话**里逐条输入，看助手是否加载本技能（出现"冻结账本/失败归因"这类步骤即算命中）。不要在同一条消息里提示技能名称。

判定：命中 = 自动加载并走对应模式（守卫看"冻结账本/失败归因"，反推看"先查后问/意图卡"）；未命中 = 直接给出改写稿或直接回答，不报步骤。
目标：守卫组 A+B+C ≥ 10/12，反推组 E ≥ 4/5；不应触发组 D ≥ 4/5、F ≥ 2/3。

## E. 应该触发「反推模式」（v2.2.0 新增，5 条）

判定标准不同：命中 = 出现"先查后问 / 缺口扫描 / 意图卡"这类步骤，而**不是**出现"冻结账本"。如果它直接甩一段提示词出来、不问也不给意图卡，算命中但档位判错。

| # | 输入 | 预期 |
|---|---|---|
| E1 | 我想要 AI 帮我写周报，怎么写 | 触发 · 反推（大概率 0 问档 + 意图卡） |
| E2 | 它老是不按我想的来，我该怎么跟它说 | 触发 · 反推（大概率轻问档） |
| E3 | 帮我想清楚我到底要什么 | 触发 · 反推（大概率深挖档） |
| E4 | 怎么说 AI 才懂我要的是这个 | 触发 · 反推 |
