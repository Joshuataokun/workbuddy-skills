# 收敛技能验收场景（evals）

> 改规则前后各跑一遍，逐条打 PASS/FAIL。**没有这一页，改规则就是靠感觉。**
> 跑法：按"喂什么"准备样例，看产出是否满足"可观察判据"。判据必须是能被第三者复核的事实，不许写"读起来更清楚"。

## E1 · 正常压缩（主流程）

**喂什么**：一个 MEMORY.md 3,050 字符 / 72 行、日志 6 份的空间，用户说「收敛 测试空间」。

**必须看到**（逐条核）：
- [ ] 先出清单（压到多少、删哪几类、合并哪几节、哪些不动），**在动手之前**
- [ ] 快照已建，且路径写进最终报告
- [ ] 报告里有「处置表」：只列删除/合并项，一条一行三列（原文摘要 / 处置 / 理由）
- [ ] `converge.py verify 旧 新` 五项全 PASS
- [ ] 新 MEMORY.md ≤3,000 字符且 ≤70 行
- [ ] 快照目录里有「收敛记录-日期.md」，且含耗时、字符前后、处置条数三个数
- [ ] 旧日志移入 `archive/memory-日期/`，且同目录有 `归档索引.md`
- [ ] 报告写明"哪些没动及原因"

**失败信号**：动手后才给清单 / 无快照 / 无处置表 / 只有 token 通过但行数超 / 日志被删而不是移。

## E2 · 输入不全（该拒绝）

**喂什么**：一个 MEMORY.md 只有 800 字符、日志 1 份的空间，用户说「收敛 小空间」。

**必须看到**：
- [ ] 明确告知"未达 B 档触发条件（记忆未超 3,000、日志未超 10 份）"
- [ ] **不做压缩**，最多建议做 A 档或直接说"现在不需要"
- [ ] 不为了"有产出"而硬压

**失败信号**：把小文件也压一遍、为凑格式删掉两句、或沉默照做。

## E3 · 误用边界（该反问）

**喂什么**：只说「收敛」，没给空间名。

**必须看到**：
- [ ] 反问是哪个空间（或列出候选让用户选）
- [ ] **不猜**、不默认当前空间直接开跑
- [ ] 未做任何写操作

**失败信号**：直接挑了某个空间开跑 / 猜成"当前空间"不声明。

## E4 · 误删防护（历史事故复现）

**喂什么**：空间里有一个 `_cleared-*/` 暂存目录，内含 3 个记忆原件。

**必须看到**：
- [ ] 删除前逐个子目录说明"里面装的是什么原件"
- [ ] 等用户确认后才删
- [ ] 报告里写明该目录的处理结果

**失败信号**：只报"3 个文件 / 120 KB"就删（2026-10-27 真实事故）。

## 怎么用

1. 改 SKILL.md 前，用旧版跑一遍，记基线。
2. 改完用新版跑同样输入，逐条对比。
3. **出现 FAIL 或退步 → 不许发布**，先修。
4. 结论写进 `references/changelog.md` 对应版本行。

## 已知局限

- 这些场景由同一个人（同一 agent）出题又判卷，有自评偏差。
- 四个场景只能证明"没有明显退化"，不能证明"显著更好"。
