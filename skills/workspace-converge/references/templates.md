# 模板（照抄即可）

## 一、处置表（压记忆时必须附）

纯文本列，三列一行，**只列删除和合并的项**，原样保留的不列。不用 Markdown 表格——粘进指令框会乱。

```
处置表
1. 原文摘要：xxx（约 N 字）→ 处置：删 → 理由：过程叙述，日志 2026-10-29 可查
2. 原文摘要：yyy → 处置：并入第 5 条「证据与检索」→ 理由：同一主题重复表述
3. 原文摘要：zzz → 处置：改指针（细则见技能 X）→ 理由：别处有副本，避免两处漂
```

规则：一条一行，摘要不超 30 字；理由必须能指回"为什么"，不许写"冗余"了事；原样保留的不列，但要说明"保留 N 条，见正文"。

## 二、归档索引（蒸日志时必须建）

放在 `archive/memory-<日期>/` 下，文件名 `归档索引.md`。

```markdown
# 归档索引 · memory-YYYYMMDD

> 本目录是 YYYY-MM-DD 收敛时移出的旧日志。**只移不删，可直接搬回。**
> 搬回：把本目录的 *.md 复制回 ../../memory/ 即可。

| 文件 | 字符 | 里面有什么（结论已在 MEMORY.md，这里留过程与细节） |
|---|---|---|
| 2026-10-27.md | 9,325 | 一句话概括三到五件事 |

**找东西建议**：结论看 `../../memory/MEMORY.md`；追"当时怎么做的"再来这里按日期翻。
```

## 三、收敛记录（B 档收尾必须写）

放在**快照目录**里，文件名 `收敛记录-<日期>.md`。**这是审计账，不写进 MEMORY.md。**

```markdown
# 收敛记录 · YYYY-MM-DD HH:MM

> 回滚点：memory-snapshot-YYYYMMDD/（改动前原件）

## 改了什么
| 对象 | 动作 | 前 → 后 |

## 度量（三个数，缺一不可）
- 耗时：从出清单到报告完 ____ 分钟
- 字符：____ → ____（-__%），行数 ____ → ____
- 处置表：删除 __ 条 / 合并 __ 条 / 改指针 __ 条

## 核验
converge.py verify 五项结果：____

## 没动什么及原因

## 删除项（逐条写原因；没有就写「零删除」）
```

## 四、快照（用脚本，别手抄）

```bash
python scripts/converge.py snapshot <空间目录或文件> --label YYYYMMDD
```

它会复制并**逐文件 md5 校验**，输出"不一致 0"才算成功。手抄 copy 不校验，等于没验过。
